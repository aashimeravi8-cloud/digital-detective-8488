### Task 4.2 — Compare Compiler and Interpreter

| Point | Compiler | Interpreter |
|---|---|---|
| When translation / execution happens | Translates the source code before execution. | Executes instructions at runtime. |
| Typical output | Machine code or an executable file. | Executes instructions without usually creating a separate executable. |
| One example | C compiler | Python interpreter |
| One advantage | Compiled programs can run efficiently. | Easy to test and debug programs. |

### Difference Between Compiler and Interpreter

- A compiler translates the source code into another form before the program runs.
- An interpreter reads and executes instructions at runtime.
- A compiler often produces an executable file, while an interpreter executes the program directly.
- Both are used to run programs, but their execution methods are different.
