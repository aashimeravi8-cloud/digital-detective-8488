### Task 3.2 — Understand Processes

- A process is a program that is currently running on a computer.
- PID stands for Process ID.
- Every running process has a unique process identifier.
- The PID helps the operating system identify and manage processes.
- Examples of processes:
  - Google Chrome
  - VS Code

### Task 3.3 — Understand Paths and Permissions

**Difference between absolute and relative paths:**

- An absolute path gives the complete location of a file or folder.
- A relative path gives the location based on the current working directory.

**File permissions:**

| Permission | Meaning | Example |
|---|---|---|
| r — Read | Allows reading a file. | Opening a text file. |
| w — Write | Allows modifying a file. | Editing a document. |
| x — Execute | Allows running a program. | Running a Python script. |
