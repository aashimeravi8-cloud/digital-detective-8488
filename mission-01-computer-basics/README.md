Understand how a computer receives input, processes information, produces output and stores data. Identify hardware, software and everyday computer-based systems.

## 4. My understanding

- Input means entering data into a computer.
- Processing means converting input into useful information.
- Output means displaying the processed information.
- Storage means saving data for future use.
- Hardware refers to the physical parts of a computer.
- Software refers to the programs that run on a computer.
- IPOS explains how a computer performs different tasks.
