## 3. Commands / tools used

- 'git status' – Checks repository status.
- 'git add' – Stages selected changes.
- 'git commit' – Saves changes in Git history.
- 'git log --oneline' – Displays commit history.
- 'git switch -c' – Creates and switches to a branch.
- 'git branch' – Lists available branches.
- 'git push' – Publishes commits to GitHub.
- 'git pull' – Retrieves remote changes.
- GitHub – Used to create and review a Pull Request.

## 4. My understanding

Git is a version control system that tracks changes in files. GitHub is an online platform used to store repositories and collaborate with others.

Staging means selecting changes before committing them. A commit saves those selected changes in Git history.

A branch allows us to work separately without directly changing the main branch. A Pull Request allows us to review proposed changes before merging them into the main branch.
